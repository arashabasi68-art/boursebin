# بورس‌بین

وب‌سایت و PWA فارسی برای تحلیل تکنیکال و بنیادی بورس ایران، فارکس، کریپتو و ارز و طلا.
**محتوا صرفاً آموزشی است و توصیهٔ قطعی خرید یا فروش نیست. همهٔ قیمت‌ها و نمودارها نمونه‌اند.**

## ساختار
- `index.html`: کل برنامه (HTML، CSS و JS در یک فایل، بدون نیاز به build)
- `manifest.webmanifest`، `sw.js`، `icons/`: نصب‌پذیری روی اندروید و حالت آفلاین
- `.nojekyll`: جلوگیری از پردازش Jekyll در GitHub Pages

## انتشار روی GitHub Pages
1. یک مخزن جدید بسازید و محتوای این پوشه را در ریشهٔ آن آپلود کنید.
2. Settings ← Pages ← Source: «Deploy from a branch»، شاخهٔ `main` و پوشهٔ `/ (root)`.
3. بعد از یک دقیقه آدرس `https://USERNAME.github.io/REPO/` فعال می‌شود.

## نصب روی اندروید
آدرس سایت را در Chrome باز کنید ← منو ← «Install app» یا «افزودن به صفحهٔ اصلی».

## ذخیره‌سازی داده
- حساب‌ها، دیدبان و دفتر معاملات فقط در `localStorage` همان مرورگر ذخیره می‌شوند (بدون سرور).
- ورود با نام کاربری و رمز، پروفایل‌های جدای محلی می‌سازد؛ امنیت واقعی چنددستگاهی به بک‌اند نیاز دارد.
- پرداخت به درگاه وصل نیست؛ پلن‌ها و قیمت‌ها نمونه‌اند و در `index.html` (آرایهٔ `PLANS` و `PRODUCTS`) ویرایش می‌شوند.

## به‌روزرسانی
بعد از تغییر `index.html`، عدد `VERSION` در `sw.js` را عوض کنید تا کاربران نسخهٔ جدید را بگیرند.
