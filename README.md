# بورس‌بین

وب‌سایت، PWA و برنامهٔ اندروید فارسی برای تحلیل تکنیکال و بنیادی بورس ایران، فارکس، کریپتو و ارز و طلا.
**محتوا صرفاً آموزشی است و توصیهٔ قطعی خرید یا فروش نیست. همهٔ قیمت‌ها و نمودارهای نمونه ساختگی‌اند.**

## امکانات
- تحلیل تکنیکال خودکار (RSI، MACD، بولینگر، ATR، حمایت و مقاومت، الگوهای کندلی، فیبوناچی) برای حدود ۱۰۰ نماد و افزودن نماد دلخواه
- اسکنر بازار، تفسیر خبر جدا برای هر بازار، پیشنهادهای نمونه، ماشین‌حساب ریسک و P/E
- قیمت زنده و رایگان: کریپتو از Binance (یا Bybit) و فارکس از Frankfurter (نرخ روزانهٔ بانک مرکزی اروپا) با یک کلیک؛ بدون سرور و بدون کلید API
- ابزارهای TradingView (نمودار پیشرفته، سنجش تکنیکال، تقویم اقتصادی، نمای بازار)
- آموزش: کتابچهٔ جامع علم اقتصاد (۲۸ فصل) با جستجو، نشانک و پیشرفت مطالعه
- حساب کاربری محلی (نام کاربری و رمز، مدیر و کاربران)، دیدبان، دفتر معاملات، سفارش‌ها، قفل رمز عددی
- پلن‌ها و فروش (نمونه، بدون درگاه پرداخت)

## ساختار
- `index.html`: کل برنامه در یک فایل (بدون build)
- `manifest.webmanifest`، `sw.js`، `icons/`: PWA و حالت آفلاین
- `package.json`، `capacitor.config.json`، `scripts/`، `android-icons/`، `.github/workflows/android.yml`: ساخت برنامهٔ اندروید

## انتشار سایت (GitHub Pages)
Settings ← Pages ← Source: Deploy from a branch ← `main` و `/ (root)`.
(برای مخزن Private در پلن رایگان Pages کار نمی‌کند؛ مخزن را Public کنید.)

## ساخت APK اندروید (بدون نصب Android Studio)
1. مخزن شامل پوشهٔ `.github/workflows/android.yml` باشد.
2. تب **Actions** ← «Build Android APK» ← **Run workflow**.
3. بعد از ۵ تا ۱۰ دقیقه، در پایین صفحهٔ اجرا، فایل **boursebin-debug-apk** را دانلود کنید و از داخلش `app-debug.apk` را روی گوشی نصب کنید (اجازهٔ «نصب از منبع ناشناس» لازم است).
4. برای انتشار در کافه‌بازار یا مایکت باید نسخهٔ Release با کلید امضای خودتان ساخته شود. این پروژه فقط APK آزمایشی (debug) می‌سازد.

### ساخت محلی (اختیاری)
```
npm install
node scripts/prepare-www.js
npx cap add android
node scripts/android-tweaks.js
npx cap sync android
cd android && ./gradlew assembleDebug
```
نیاز: Node 20 و JDK 17.

## ذخیرهٔ داده
حساب‌ها، دیدبان، دفتر معاملات و پیشرفت آموزش فقط در `localStorage` همان مرورگر یا برنامه ذخیره می‌شوند (بدون سرور). ورود چنددستگاهی، بازیابی رمز و پرداخت واقعی به بک‌اند نیاز دارد.

## داده زنده
دکمهٔ «دریافت قیمت زنده» فقط روی نمادهای کریپتو و جفت‌ارزهای پشتیبانی‌شده دیده می‌شود. درخواست مستقیم از مرورگر به سرویس‌های رایگان زده می‌شود؛ بورس ایران و طلا/سکه منبع رایگان و پایدار مرورگری ندارند و روی داده نمونه می‌مانند (می‌توانید با «افزودن نماد دلخواه» قیمت‌های واقعی را خودتان وارد کنید). بعضی سرویس‌ها در ایران بدون تغییر IP باز نمی‌شوند.

## TradingView
ابزارها از سرورهای TradingView بارگذاری می‌شوند و اینترنت می‌خواهند. بورس تهران در TradingView نیست.

## به‌روزرسانی
بعد از تغییر `index.html`، عدد `VERSION` در `sw.js` را عوض کنید.
